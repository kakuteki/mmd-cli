# スパイク結果 (2026-10-04)

MikuMikuDance v9.32 (x64) を Windows 11 で実測した結果。設計書の根拠になる事実だけを書く。

## 窓とコントロール

- 主窓のクラス名は `Polygon Movie Maker`。子コントロールは 168 個で、すべて主窓の直下にある。
- コントロール ID は 400〜567、メニュー ID は 200〜302。一覧は `mmd_cli/ids.py`。
- MMD は DPI 非対応のプログラムで、座標は 96 dpi の論理座標で返る。
- 起動直後の窓は最大化の復帰設定を持つ。最小化から通常表示へ戻すと全画面になるので、戻さない。
- `SetWindowPlacement` は画面外の座標を画面内へ補正する。画面外へ置くには `SetWindowPos` を使う。

## 裏からの操作

| 操作 | 結果 |
| --- | --- |
| ボタン: 主窓へ `WM_COMMAND(BN_CLICKED)` | 効く。`BM_CLICK` でも効く |
| フレーム番号: 入力欄 417 へ `WM_SETTEXT` + Enter の `WM_KEYDOWN` を投函 | 効く |
| フレーム番号: 入力欄 554 へ値を入れて Go（553） | 効く。同期で完了が分かる |
| `WM_CHAR` の改行、`EN_KILLFOCUS` の通知 | 効かない |
| カメラ値: 入力欄 544〜550 + Enter | 効く。確定後は MMD が書式を整える（`1.5` → `1.50`） |
| モデル切替: コンボ 436 へ `CB_SETCURSEL` + `CBN_SELCHANGE` | 効く。パネルの表示も切り替わる |
| 上書き保存: メニュー 207 | ダイアログなしで保存される（パスがあるとき） |

最小化のままでも上のすべてが効く。主窓の題名は、プロジェクトにパスがあると
`MikuMikuDance [C:\...\x.pmm]` になる。

## ファイルを落とす（WM_DROPFILES）

- `GlobalAlloc` で作った `DROPFILES` を `PostMessage` で投函すると、別プロセスでも受け取られる。
- `SendMessage` で送ると受け取られない（投函の経路でだけハンドルが相手側へ写される）。
- pmx / pmd / vmd / vpd / wav / x のすべてで読み込まれた。
- モデルを落とすと「モデル情報」ダイアログ（OK / キャンセル、本文はモデルのコメント）が出る。
  OK を押すまで読み込まれない。
- vmd を落とすと、vmd 内のモデル名が選択中のモデル名と違うとき「モーションデータ読込」の確認が出る。
  キーは現在のフレームを起点に取り込まれ、モデルに無いボーン名は無視される。
- vpd を落とすと現在のポーズが変わるが、キーは登録されない。

## ダイアログ

- 最小化していても、ダイアログは画面の中央や左上に出る。
- 窓が作られてから表示されるまでに数十 ms あり、1 ms 間隔の見張りで表示前に捕まえられる。
- 表示前に `WS_EX_LAYERED` と不透明度 0 を付けると、表示された時点でも不透明度 0 のままだった。
- ファイル選択ダイアログは初期化の途中で自分の位置を画面内へ戻す。透明化が要るのはこのため。
- 開くダイアログは旧式（ファイル名の入力欄の ID は 1148）、保存ダイアログは新式（同 1001）。
  どちらも入力欄へ `WM_SETTEXT`、既定ボタン（ID 1）へ `BM_CLICK` で通る。
- 画像の書き出しは、ハンドラが戻ったあとに `RecWindow`（題名は「録画中(N frame)」）が出て、
  その後にファイルが書かれる。
- AVI の書き出しは、ファイル選択のあとに「AVI出力設定」が出る。大きさ 612 / 613、fps 611、
  範囲 609 / 610、コーデックのコンボ 628。

## 見えない別デスクトップ

`CreateDesktop` で作ったデスクトップで MMD を起動すると、窓メッセージのやり取りはできるが、
`Direct3D::Init` / `CreateDevice Failed!` のダイアログが出て初期化に失敗する。採れない。

## 描画

- 最小化のままでも、画面外へ置いたままでも、「画像ファイルに出力」は正しい絵を書き出す。
- 画面外に置いた窓を `PrintWindow` で取り込むと、3D 画面の部分は真っ黒になる。

## pmm

- 先頭は `Polygon Movie maker 0002`。30 バイトの残りは不定値。
- 既知の構造どおりに読むと、ファイルの末尾までちょうど読み切れた。
- モデルのパスは MMD のフォルダの下でも絶対パスで入る。
- カメラの現在値は、角度がラジアンで X の符号が画面表示と逆、距離は負の値で入る。
- キーフレームの `data_index` は格納位置で、どのボーンのキーかは前後のつながり（`pre_index`）を
  初期フレームまで辿って決める。
- 同梱の見本 pmm は版 0001 で、構造が違う。読み取りの対象は 0002 だけにする。
